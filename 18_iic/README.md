2.全双工模式下，驱动要求“发送长度 >= 接收长度”，然后再代码中只设置了rx的相关函数就是相当于发送为0，就导致报错了，把它设置成半双工，还有就是0x03是典型的半双工，先往 MOSI 上发命令和地址，然后总线方向切换，数据从 MISO 读回来。

为什么发送>=接收，这样不会导致数据的丢失吗

答：SPI的发送和接收不是两个独立的过程而是同时发生的，所以并不会把多的数据丢失了，注意时钟是由主机也就是esp32产生的，esp32属于发送方，如果发送方不产生时钟，接收方想往外发数据是不可能的
