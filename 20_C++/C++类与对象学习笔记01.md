C++类与对象学习笔记

1.

权限问题：有三种权限public：类内类外都可以访问
protected：类内可以，类外不可以（子可以继承父）
private：类内可以，类外不可以（子不可以继承父）

struct和class的区别：struct默认权限是公有，class默认权限是私有

2.

成员属性设置为私有可以自己控制读写权限，对于写权限可以检测数据的有效性；

设置成私有之后可以在类里面通过pubilc函数来从外部更改或者获取值

一般都是把属性设置成私有，然后通过public来获取和设置

4.

构造函数的分类：有参和无参

​				普通和拷贝

```c++
class Person {
pubilc :
	Person (){
		cout<<"无参构造:"<<endl;
	}
	Person （int A）{
		age =A;
		cout<<"有参构造"<<endl;
	}
	Person(const Person &p){//将P这个对象的所有属性都给这个拷贝函数
		cout << "拷贝构造"<<endl;
		age=p.age
	}
	~Person(){
		cout <<"析构函数"<<endl;
	}
	int age ;
	
}
//如何调用呢
void test(){
    //括号法
    Person p1;//调用的是无参构造
    Person p2(10);//调用的是有参构造
    Person p3(p2);//调用拷贝构造，且用的是p2 的age
    //显示法
    Person p1;//无参
    Person p2=Person (10);//有参
    Person p3=Person (p2);//构造
    //隐式转换法
    Person p4=10;//等价与Person p4=Person (10);
    //需要注意的是无参构造不要加（），否则编译器会认为这是一个函数声明
}
```
